# Mockups – Archiv (E-64)

Die Dateien in diesem Ordner sind die freigegebenen Entwürfe aus AP-2 (Variante A „Plakat“, E-36) und spätere Entwürfe zu einzelnen Seiten. Sie bleiben als Nachweis, wie die Gestaltung entstanden ist.

**Sie sind nicht mehr die Vorlage.** Seit AP-17 (Admin 2026-10-31, E-64 (1)) gilt:

- Die einzige Quelle der Gestaltung ist `server/public/assets/site.css`.
- Zum Ansehen dient das Komponentenblatt in der App: Team-Bereich → Betrieb → Komponenten (`/team/komponenten`, nur BetreiberInnen). Es zeigt jede Komponente mit ihren Varianten und dem Aufruf, mit dem eine Seite sie erzeugt.
- Neue Entwürfe für Seiten entstehen als Mockup gern weiter hier, werden aber in der Umsetzung aus den vorhandenen Komponenten gebaut; was fehlt, kommt mit Eintrag im Komponentenblatt dazu.

Die Mockups haben eigene Stile und Tokens, die vom Stand der App abweichen können.
